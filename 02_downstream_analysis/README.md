# PhotoSeq downstream analysis

This directory contains the Windows R/Python workflow used for downstream PhotoSeq analysis. Run commands from this directory so that all relative paths resolve correctly.

## Directory layout

```text
02_downstream_analysis/
├── input/             # PhotoSeq count matrices and sample metadata
├── reference/         # Immune signatures, KEGG tables, benchmarks and UV source data
├── environment/       # Recorded R, Python and package versions
├── scripts/           # Numbered R scripts and unnumbered helper scripts
└── run_all_analysis.R # Sequential runner
```

Generated matrices, result tables and figures are written to numbered output folders. Those folders are not pre-populated in the repository. PPI tables and figures are generated within `12_Venn_All/04.PPI/`. The compact frozen PPI snapshot under `reference/ppi/` is included to preserve the STRING response used for the reported network.

## Operating system and working directory

The downstream analysis was run on Windows 11 with R 4.6.0 and Python 3.12.14. Using Linux for upstream FASTQ processing and Windows for downstream analysis is valid because the interface between the stages is a platform-independent CSV gene-count matrix. All repository paths are relative.

In RStudio, set the working directory to `02_downstream_analysis/`. From PowerShell or Command Prompt:

```powershell
cd PhotoSeq_GitHub_submission\02_downstream_analysis
R -e "renv::load(); source('scripts/00_prepare_analysis_data.R')"
```

## Inputs

The following files are the primary PhotoSeq inputs:

| File | Role |
| --- | --- |
| `input/PhotoSeq_Spatial_GeneCounts.csv` | Spatial gene-count matrix |
| `input/PhotoSeq_Temporal_GeneCounts.csv` | Temporal gene-count matrix |
| `input/PhotoSeq_TechnicalReplicate_GeneCounts.csv` | Technical-replicate count matrix used by script 17 |
| `input/PhotoSeq_sample_metadata.csv` | Sample condition, replicate, barcode and sequencing-batch metadata |

The `reference/` subdirectories contain the smaller supporting inputs required by the immune-scoring, enrichment, benchmarking and UV analyses. Their roles and derivation are described in [reference/README.md](reference/README.md).

No additional input file is required by the scripts included here. The raw FASTQ files and genome reference are required only for rerunning the upstream workflow.

## Technical replicate

`Breast_early_N1` and `Breast_early_N1_techrep2` are technical measurements of the same biological sample. Script 17 checks their reproducibility using `log2(count + 1)` values without batch correction.

## PPI analysis

The five-way intersection generated by script 12 uses two Spatial contrasts and
three Temporal contrasts. Each
DESeq2 model uses `design = ~ sequencing_batch + condition`; genes are retained
in a contrast at adjusted *P* < 0.01 and absolute log2 fold change > 1.5. The
intersection of all five significant-gene sets contains fifty genes.

The deterministic default run uses the STRING response recorded on 2 September
2026 under `reference/ppi/`. It represents a *Mus musculus* functional network
with no additional interactors and a minimum required STRING score of 400;
interactions with a returned score greater than 0.4 are retained. By default,
script 12 uses this frozen response. To query the live STRING database while
rerunning script 12 in PowerShell:

```powershell
$env:PHOTOSEQ_REFRESH_STRING = "true"
Rscript scripts\12_integrated_shared_gene_analysis.R
```

Live STRING responses can change over time. The frozen response reproduces the
reported network, whereas a refreshed response represents a separate analysis
version.

Degree and maximal clique centrality (MCC) are calculated directly from the
undirected retained network. The MCODE implementation uses degree cutoff 2,
node-score cutoff 0.2, haircut enabled, fluff disabled, K-core 2 and maximum
depth 100. The only module contains five nodes and nine internal edges and has
a score of 4.5. Candidate genes are defined by agreement among the MCC top five,
Degree top five and the MCODE module: `Actg1`, `Itga3`, `Itga8`, `Itga9` and
`Lama4`.

The MCODE figure panel intentionally retains the complete fourteen-node,
sixteen-edge PPI network and highlights the five module genes within it. The
PPI panel uses weighted PPI strength; the MCC and Degree panels use their named
metrics. `Itga8` is marked as a highlighted candidate gene.

## Data integration rule

The Spatial and Temporal matrices share the Breast-mid and Lung-metastasis profiles. Script 00 verifies and retains one copy of those shared profiles when constructing the 24-profile integrated matrix; it does not treat the duplicates as additional biological replicates.
