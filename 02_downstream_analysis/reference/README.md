# Supporting reference inputs

## Immune-cell signatures

`immune/CellReports_TISIDB_GMT.txt` contains the supplied human immune-cell signatures. `immune/mmc3_ssGSEA.txt` is its two-column gene-to-cell-type representation. Human genes were mapped to mouse homologs using `immune/HOM_MouseHumanSequence.rpt`, producing `immune/mmc3_ssGSEA_mouse.txt`. The downstream immune-scoring scripts use the mouse table.

These files are reference inputs, not outputs generated by `00_prepare_analysis_data.R`. They are included so the immune-scoring analyses can be rerun without an external download step. `scripts/prepare_immune_signature.R` documents and reproduces the conversion.

To regenerate the two processed signature tables, run this command from `02_downstream_analysis/`:

```powershell
Rscript scripts\prepare_immune_signature.R
```

## KEGG

`kegg/kegg_link_mmu_pathway.txt` maps mouse Entrez gene identifiers to KEGG pathway identifiers. `kegg/kegg_list_pathway_mmu.txt` maps pathway identifiers to names. Scripts 05, 10 and 16 read these files directly; they are not generated by script 00.

## Benchmark tables

The three files under `benchmark/` are processed comparison inputs used for PhotoSeq-versus-Visium quality-control panels. The benchmarking analysis in script 17 uses frozen reference tables derived from publicly available Visium data for GEO samples `GSM8210411` and `GSM8210412`. Script 17 recalculates the PhotoSeq side from the supplied PhotoSeq counts and reads the Visium-side quantities from these compact tables. The corresponding Visium HDF5 files are not redistributed in this repository; preprocessing of these public reference data is described in the manuscript Methods.

## UV condition optimization

`uv/uv_pair_source_data.xlsx` contains the fluorescence measurements used to generate the UV power and exposure-time panels in script 17.

## Protein-protein interaction analysis

`ppi/` contains the five-way DEG intersection, the frozen STRING mapping and
network responses, and compact expected source tables for the PPI analysis.
The frozen response makes the reported network reproducible even if the live
STRING database changes. See [ppi/README.md](ppi/README.md) for the query
settings, network counts, candidate-gene definition and file-level details.
